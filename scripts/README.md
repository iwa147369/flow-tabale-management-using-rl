# FlowRL Pipeline Scripts

This directory contains helper scripts for the experiment → trace collection → training workflow.

**See the authoritative and up-to-date guide in `docs/memory.md`** (section "How to Collect Real Traces from Mininet").

The `run_pipeline.py` script provides convenient stage-based commands (`experiment`, `organize`, `train`, `full`) and generates helper files for the VM.

For the current limitations and recommended usage, refer to the documentation in `memory.md` and the tutorial page `docs/tutorials/running-mininet-experiments.html`.
